## 🛠️ Herramientas y tecnologías utilizadas

- **Microsoft SQL Server y SQL Server Management Studio (SSMS):** creación del esquema físico y consultas SQL.
- **SQL (T-SQL):** definición de tablas, llaves, restricciones e inserción de datos.
- **draw.io / diagrams.net:** elaboración del modelo entidad-relación.
- **Mermaid:** diagramas UML, mapas conceptuales y diagramas del proceso de normalización.
- **SVG y PDF:** presentación de reportes y recursos visuales.
- **GitHub y YouTube:** publicación de los entregables y sus explicaciones.
